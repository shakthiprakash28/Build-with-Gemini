# Glossary

| Term | Definition |
|---|---|
| Agent | Autonomous software that plans and performs multi-step actions toward a goal |
| ADK | Agent Development Kit: open-source Google framework for building/deploying agents |
| Agent CLI | CLI + skills in Gemini Enterprise Agent Platform that drives ADK from a coding agent |
| Skill | Instruction set that tells a coding agent how to do a task |
| ADC | Application Default Credentials: recommended Google auth method vs long-lived keys |
| MCP | Model Context Protocol: connects agents to tools/data (e.g. Kubernetes) |
| RAG | Retrieval-Augmented Generation: grounding answers in retrieved data |
| Model Garden | Catalogue of Google and third-party models |
| Agent Evaluation | Measuring correctness/trustworthiness of agent output |
| Agent Runtime | Managed environment to deploy and scale agents |
| Memory Bank | Persistent agent memory across sessions |
| Agent Identity | Unique identity per agent for access control |
| SPIFFE ID | Standard workload identity format used for agent identity |
| Agent Registry / Policies / Gateway | Governance features (discovery, guardrails, controlled access) |
| Agent Studio | UI-based agent builder |
| Day-1 ops | Building a working prototype |
| Day-2 ops | Operating it in production: trust, scale, memory, identity, observability, cost |
